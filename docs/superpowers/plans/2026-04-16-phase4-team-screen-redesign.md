# Phase 4: Team Screen Redesign

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Redesign the Team screen from a simple list with inline-styled JS to a professional card-grid overview and detail page matching the approved mockup — using CSS classes, CSS variables, and the existing design system.

**Architecture:** The Team tab has two views: Overview (card grid of all teams) and Detail (single team with members + shared docs). Unlike Phase 3 (static HTML), Team HTML is dynamically generated by JS functions. The redesign replaces inline styles in `ladeTeams()`, `zeigeTeamDetail()`, `ladeTeamMitglieder()`, and `ladeGeteilteSessionen()` with CSS classes. The Detail view now loads both members AND docs automatically (no tab-switching). No backend changes needed.

**Tech Stack:** HTML, CSS Custom Properties, Vanilla JS, Lucide Icons

**Spec Reference:** `docs/superpowers/specs/2026-04-11-complete-redesign.md` Section 10

**Mockup Reference:** `docs/mockups/13-team-final.html`

### API-Endpunkte (unverändert)

- `GET /teams/:userId` → Liste aller Teams
- `POST /teams` → Team erstellen
- `DELETE /teams/:teamId` → Team löschen
- `GET /teams/:teamId/members?user_id=` → Mitglieder laden
- `POST /teams/:teamId/invite` → Mitglied einladen
- `DELETE /teams/:teamId/members/:memberId` → Mitglied entfernen
- `GET /teams/:teamId/shared?user_id=` → Geteilte Dokumente laden

    async function ladeTeams() {
      const { data: { session } } = await supabaseClient.auth.getSession();
      const user = session?.user;
      if (!user) return;
      const container = document.getElementById('teamListe');
      const overview = document.getElementById('teamsOverview');
      const detail = document.getElementById('teamDetail');
      overview.style.display = '';
      detail.style.display = 'none';
      container.innerHTML = '<div class="teams-loading">Lädt...</div>';
      const res = await fetch(`/teams/${user.id}`, { headers: { 'x-user-id': user.id } });
      const teams = await res.json();
      if (!teams.length) {
        container.innerHTML = `
          <div class="teams-empty">
            <div class="teams-empty-icon">👥</div>
            <p>Noch kein Team. Erstelle dein erstes Team!</p>
          </div>`;
        return;
      }
      container.innerHTML = teams.map(t => {
        const initial = t.name.charAt(0).toUpperCase();
        const roleLabel = t.role === 'owner' ? 'Owner' : 'Mitglied';
        return `
          <div class="team-overview-card" onclick="zeigeTeamDetail('${t.id}', '${escapeHtml(t.name)}')">
            ${t.role === 'owner' ? `<button class="team-card-delete" onclick="event.stopPropagation();loescheTeam('${t.id}','${escapeHtml(t.name)}')" title="Team löschen"><i data-lucide="trash-2" style="width:14px;height:14px;"></i></button>` : ''}
            <div class="team-overview-card-header">
              <div class="team-overview-icon">${initial}</div>
              <div>
                <div class="team-overview-name">${escapeHtml(t.name)}</div>
                <div class="team-overview-role">${roleLabel}</div>
              </div>
            </div>
            <div class="team-overview-stats">
              <div class="team-stat"><span class="team-stat-num">${t.member_count || '—'}</span> Mitglieder</div>
              <div class="team-stat"><span class="team-stat-num">${t.shared_count || '—'}</span> Dokumente</div>
            </div>
          </div>`;
      }).join('');
      if (typeof lucide !== 'undefined') lucide.createIcons();
    }
```

Note: The API `GET /teams/:userId` returns `{ id, name, role }` per team. The fields `member_count` and `shared_count` may not exist in the current API response — in that case they show "—". This is acceptable; the avatar stack (from mockup) is omitted because individual member data isn't available in the team list endpoint. The card still looks professional without it.

    async function ladeTeamMitglieder(teamId) {
      const container = document.getElementById('teamMembersCard');
      const { data: { session } } = await supabaseClient.auth.getSession();
      const user = session?.user;
      const res = await fetch(`/teams/${teamId}/members?user_id=${user.id}`, { headers: { 'x-user-id': user.id } });
      const members = await res.json();
      if (!Array.isArray(members) || !members.length) {
        container.innerHTML = `
          <div class="team-card">
            <div class="team-card-header">
              <span class="team-card-label">Mitglieder</span>
              <button class="team-card-action" onclick="ladeTeamMitgliederEinladen('${teamId}')">+ Einladen</button>
            </div>
            <div style="padding:20px;color:var(--text-muted);font-size:13px;">Keine Mitglieder.</div>
          </div>`;
        return;
      }
      const isOwner = members.some(m => m.user_id === user.id && m.role === 'owner');
      // Update subtitle with member count
      const subtitle = document.getElementById('teamDetailSubtitle');
      if (subtitle) subtitle.textContent = `${members.length} Mitglieder`;
      container.innerHTML = `
        <div class="team-card">
          <div class="team-card-header">
            <span class="team-card-label">Mitglieder (${members.length})</span>
            <button class="team-card-action" onclick="ladeTeamMitgliederEinladen('${teamId}')">+ Einladen</button>
          </div>
          ${members.map(m => {
            const label = m.email || m.user_id || 'Unbekannt';
            const initial = label.charAt(0).toUpperCase();
            const isYou = m.user_id === user.id;
            const isPending = m.status === 'invited';
            const roleClass = m.role === 'owner' ? 'role-owner' : (isPending ? 'role-pending' : 'role-member');
            const roleLabel = m.role === 'owner' ? 'Owner' : (isPending ? 'Eingeladen' : 'Mitglied');
            const deleteBtn = (isOwner && m.role !== 'owner')
              ? `<button class="member-remove-btn" onclick="event.stopPropagation();entferneMitglied(this)" data-team-id="${teamId}" data-member-id="${m.id}" data-label="${escapeHtml(label)}" title="Mitglied entfernen"><i data-lucide="trash-2" style="width:14px;height:14px;"></i></button>`
              : '';
            return `
              <div class="member-row">
                <div class="member-avatar${isYou ? ' avatar-you' : ''}${isPending ? ' avatar-pending' : ''}">${initial}</div>
                <div class="member-info">
                  <div class="member-name${isPending ? ' member-pending' : ''}">${escapeHtml(label)}${isYou ? ' (Du)' : ''}</div>
                </div>
                <span class="member-role ${roleClass}">${roleLabel}</span>
                ${deleteBtn}
              </div>`;
          }).join('')}
        </div>`;
      if (typeof lucide !== 'undefined') lucide.createIcons();
    }
```

Key changes:
- Renders into `#teamMembersCard` instead of `#teamDetailInhalt`
- Uses CSS classes instead of inline styles
- Shows initial letter in avatar circle
- "(Du)" label for current user
- Role badges with CSS classes (role-owner, role-member, role-pending)
- Invite button in card header
- Updates subtitle with member count
